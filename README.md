<h1 align="center">AskMeOut</h1>

<p align="center">
  Will you go out with me? No moves away from the pointer. Yes turns into a day, a time, and a plan.
</p>

<p align="center">
  Open index.html in a browser. No install.
</p>

## How to Use

1. Clone the repo
   ```bash
   git clone https://github.com/akhelyesa/AskMeOut.git
   ```
2. Open `index.html` in a browser

## Customize

- The question and the "Too late" lines are in `index.html`.
- `LABELS`, `TIMES`, `PLANS`, and `FOODS` are in `js/script.js`.
- The pictures are `assets/ask.png` and `assets/happy.gif`.
